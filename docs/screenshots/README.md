## 📋 截图规范

### 分辨率
- 主要截图：1920x1080（16:9）
- 移动端截图：375x812（iPhone X）
- 细节截图：根据需要调整

### 格式
- 格式：PNG（推荐）或 JPG
- 压缩：使用TinyPNG等工具压缩
- 命名：小写字母 + 连字符（如 `research-board.png`）

### 内容要求
- ✅ 使用有意义的示例数据
- ✅ 隐藏敏感信息
- ✅ 确保UI元素完整显示
- ✅ 保持一致的设计风格
- ❌ 避免个人真实信息
- ❌ 避免低质量或模糊的图片

### 浏览器要求
- 推荐使用 Chrome 最新版
- 禁用浏览器扩展（避免干扰UI）
- 使用隐身模式（避免缓存影响）
- 关闭开发者工具

## 🛠️ 截图工具推荐

### macOS
- **内置截图** - `Cmd + Shift + 4`
- **CleanShot X** - 专业截图工具
- **Snagit** - 编辑和标注

### Windows

- **Awesome Screenshot**

- **Nimbus Screenshot**

## 📐 制作步骤

### 1. 准备环境
```bash
# 启动开发服务器
pnpm dev

# 访问应用
open http://localhost:5173
```

### 2. 设置浏览器
- 全屏模式（F11）
- 缩放100%
- 清除缓存

### 3. 准备数据
- 登录测试账号
- 加载示例数据
- 确保UI状态正确

### 4. 截图
- 等待所有内容加载完成
- 调整窗口大小为1920x1080
- 按截图快捷键

### 5. 后处理
- 裁剪和调整尺寸
- 压缩图片大小
- 重命名并保存到此文件夹
